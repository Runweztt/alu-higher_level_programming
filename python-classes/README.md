# Python Classes

This project introduces Object-Oriented Programming (OOP) in Python.

Concepts covered include:
- Classes and objects
- Attributes and methods
- Public, protected and private attributes
- The __init__ constructor
- Data abstraction and encapsulation
- Getter and setter methods
- Properties in Python
- Printing objects and computing area

All tasks implement a Square class progressively to demonstrate OOP principles and attribute validation.
